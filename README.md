# SiteMaison
React + Vite + React Three Fiber + GSAP. All free tooling.

Cloudflare Pages build: `npm run build`; publish directory: `dist`.

## Run locally
    npm install
    npm run dev

## Setup
- Contact form: add a free Web3Forms key as VITE_WEB3FORMS_KEY.
- Fiverr button: set VITE_FIVERR_URL.
- Project data: edit src/data.js.
